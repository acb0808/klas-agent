# 졸업요건: 어디를 보면 되나

졸업요건은 **입학연도(학번)로 정해지고, 한번 정해지면 그 학번에게는 바뀌지 않는다.** 그래서 숫자를 외우지 않고 "이 학번이면 여기를 보라"만 정한다. 학교가 학생에게 유리하게 소급 완화한 적은 있다(예: 2025년 개편으로 2016~2024학번 필수교양 완화). 이런 변경은 학교 홈페이지 안내 페이지에 반영되므로 홈페이지를 1순위로 본다. 확인일 2026-10-29.

`www` = `https://www.kw.ac.kr/ko/life/`. 학교 페이지는 에이전트의 웹 조회 도구로 연다(스크립트로는 못 연다).

탭 안에서는 **단과대·학과 행**을 찾는다. 학과가 단과대를 옮겼으면 학과명으로 찾는다(예: 구 소프트웨어융합대학 학과들은 인공지능융합대학으로 옮겼다).

### 행을 정하는 예외

- **편입생**: 표 제목에 "2025학년도 신입학자 (2026학년도 2학년 편입생, 2027학년도 3학년 편입생 포함)"처럼 적혀 있다. 2학년 편입은 편입연도 − 1, 3학년 편입은 편입연도 − 2의 신입학 행을 본다. `graduation`의 `student.구분`과 `profile`의 편입인정학점으로 편입 여부를 확인한다.
- **특별전형**(만학도, 외국인, 특성화고 재직자, 체육특기자)·편입생: 표 아래 주석을 본다(교양필수 면제, 다전공 의무 예외 등).
- **인제니움대학 자율전공학부**: 본인이 선택한 주전공 계열 행.

### 한 번 찾으면 기억해 둔다

학번별 기준은 바뀌지 않으므로, 처음 찾은 **위치**를 전역 기억(`memory`, `## 나`)에 한 줄로 남기고 다음부터 바로 그곳을 본다. 숫자나 요약은 적지 않는다.

```
- 졸업요건 기준 위치: bachelor_info12 '<입학연도>학년도 신입생' 탭, <단과대> 행 / 기준표 PDF '<절>' 절 — <확인일> 확인
```

## 4. 출처가 다르거나 없을 때

- **홈페이지와 KLAS PDF가 다르면** 둘 다 날짜와 함께 보여주고 홈페이지를 우선하되 교육지원팀 확인을 권한다. 확인된 차이(2026-10-29): 2025학번 '광운인되기'가 PDF에는 필수 1학점, 홈페이지에는 폐지(총 교양학점은 유지).
- **내 학번 탭이 아직 없으면** "미게시"라고 말한다. 가장 최근 탭은 참고로만 보여주고 교육지원팀 문의를 권한다. 이전 학번 기준을 말없이 적용하지 않는다.
- `graduation`의 `rulesWarning`: 내 입학연도가 KLAS 기준표 파일 연도보다 늦다 → 1순위(홈페이지)를 본다.
- `graduation`의 `liberalArts.unknownCodes`에 0이 아닌 값: KLAS 교양 화면(9칸 고정)에 없는 영역의 학점이다. 영역 이름을 추정하지 말고 "화면에 표시되지 않는 교양 n학점"이라고 밝힌다. 2026학번의 AI리터러시·기초학문융합이 여기에 해당할 수 있다(미확인).

## 5. 새 학번이 생길 때 고칠 것

학번별 기준은 학교가 새 탭·새 PDF로 추가하므로 문서나 코드를 고칠 일은 거의 없다.

- §1 표에 새 연도 줄을 추가한다(탭 이름과 PDF 절 이름만).
- KLAS 교양 화면에 새 영역 칸이 생기면 `scripts/klas.mjs`의 `GYOYANG_AREAS`에 코드를 추가한다(`unknownCodes`로 드러난다).
